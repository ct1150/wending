# 百世问鼎 3.1.0 · 人间求仙篇

## 目标与范围

普通少年为长生与自己的出路争取功法、材料和机缘。开局交代身份、求仙动机、眼前目标与期限。界面维持单列文字、人物对话和2—3项当前行动；无职业表、反复刷经验按钮与管理面板墙。

本版实现可重玩的人间人生：凡人入门、炼气历险、筑基取舍、归宿和再世。第一世药谷开场，后世可从故谷、坊市或渡口重新求仙，受前世世界事实影响。沼泽、废墟与商路是不同机会，竞争、短缺和天气改变准备与代价。

筑基是本篇高阶成就。新篇没有元婴、幽冥、天界与三界问鼎，不用旧版内容冒充完成新篇高境界；未来扩展应承接同样的个人成长与资源因果。

## 沉浸阅读与开局

取名和掷骰在开局页一次完成。三项属性为根骨、悟性、气运，随机一项天赋，具体作用可在开局和人物详情查看。入世后不再重掷，CV2 下一世可重新取名与掷骰；旧人生不自动补掷。

顶部固定简栏显示姓名、境界、年龄和余寿，点击展开人物详情。正文仅保留最新后果与当前场景；完整往事进入历史对话抽屉。对话统一显示人物、冒号、中文引号和句末标点。选项保留自然行动描述，已知严重危险和缺少条件仍在选择前可见。

## 核心规则

- 一年360日，开局16岁；凡人和炼气寿限72年，筑基180年。历时推进年龄与世界，命损只减少个人余寿。
- 药谷急迫危机只耗日，多年修习在离谷之后，不能让“今晚”等待多年。
- 引气需要真实完整功法与至少两年修习，正常内容为三年。
- 筑基需要炼气、修为至少3、伤势不超过轻伤，以及本次消耗筑基灵物或已完成温养；内容还要求修炼场所。突破经过真实年月。
- 药、灵石、灵草、完整功法、筑基灵物与符为六类具体物品，数量不能为负。
- 辨药、藏息与御剑基础改变局部解法；学成进入传承历史，下一世最多一项生效。
- 无碍、轻伤、内伤、重伤四级伤势会累积并限制相关方法，疗伤要花真实资源或年月。
- 出生确定并保存本世机缘，读取不抽取。行动按处境与选择结算，不隐藏掷骰暴毙。
- 余寿不足的长期行动有明确寿尽提示；坚持会在成果取得前死去，不预借未来境界寿限。
- 死亡、寿尽、守望到寿终均记录生平、所得和教训，死亡次数不发奖。
- 下一世经过十六年，个人实力、伤势与物品重置，世界事实和已得方法保留；继续完整人生，不进入只有旧任务回顾的循环。

## 兼容与体验

v4与v1/v2/v3并存，旧档继续旧人生。明确确认重新开始才切入新篇，导入导出和保存失败提示继续可用。

触控目标44px、320px布局、键盘与焦点连续是验证目标。实际浏览器验证范围以QA记录为准。

## 验收

开局能理解动机与目标；修行条件真实影响突破；三类不同机缘、两种筑基办法、可解释的失败与退路；后世回应前世又继续新人生；不会十六岁元婴；旧档、损坏拒绝、无存储、导入导出、刷新不重抽有行为验证。

20—30分钟一世、真实手机触感与阅读体验仍需真人试玩，不将自动动作数折算成时长。详细作者与状态字段见 [设计契约](superpowers/specs/2026-10-25-cultivation-design.md)。
