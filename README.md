# 百世问鼎 · 肉鸽修仙（v8.0.0）

**寿元为筹，灵印相生，以神通法宝逆天破境。**

> 旧版 v7.1.1 剧情分支引擎已完整归档于 Git Tag `archive/v7.1.1-story-engine`。当前主干为全新重构的 **TypeScript + Vite + Preact** 纯本地零延迟肉鸽修仙卡牌构筑游戏，支持纯静态部署与单文件离线 HTML 试玩。

## 核心玩法特色

1. **「3+1」四大境界篇章星宿路线图**：
   - 第一卷【凡尘筑道】（炼气 → 筑基天劫）→ 第二卷【紫府金丹】（结丹 → 金丹心魔大劫）→ 第三卷【化神登仙】（化神 → 飞升九重混沌雷劫）→ 集齐 2 枚【三界道果信物】开启隐藏第四卷【上界问鼎】直面太初天道。
2. **寿元即时间货币 + 道基品阶破境**：
   - 赶路、洞府闭关、奇遇参悟与战中【燃寿禁术】均真实消耗寿元，寿尽则坐化轮回。
   - 卷内积累道基纯度（0~100）：`<50` 凡品破境留【道基裂痕】、`50~84` 地道破境、`>=85` **天道破境**（巨额延寿、真元上限 +1，并三选一金色【天道法则】）。
3. **通用真元 + 七灵印相生共鸣**：
   - 基础出牌消耗通用真元不卡手；打出金/木/水/火/土/雷/煞属性神通注入灵印槽，触发**木火焚心、金雷惊蛰、厚土锋鸣、寒泉生息、山泽固本、魔威噬魂、五行混元**七大即时共鸣。
   - 手牌自动高亮可触发相生的卡牌，配合**本命功法被动 + 本命法宝充能大招 + 古宝遗物**构筑千变 BD。
4. **四大首发修仙道统**：
   - **太白剑宗 · 剑修**：剑意叠层 + 0 费御剑连斩 + 穿甲雷剑。
   - **幽冥魔渊 · 魔修**：卖血燃寿超模爆发 + 吞噬心魔增伤 + 斩杀夺元回寿。
   - **百草丹谷 · 丹修**（轮回解锁）：木火丹毒叠层引爆 + 回生续命。
   - **玄武阵山 · 阵修**（轮回解锁）：永续阵盘自动攻防 + 罡气留存 + 以盾代攻。
5. **洞府三合一 & 百世轮回遗蜕**：
   - 洞府可【熔入天材地宝给神通打永久附魔词条】【开炉博炼九转金丹】【斩三尸删废牌/心魔】。
   - 身死或飞升后结算轮回道果解锁新道统与重掷次数，并在下一世对应篇章地图动态生成**【前世遗蜕】**节点，可继承前世附魔神通或本命法宝；飞升后逐级解锁 **天道劫数 1~9 重**。

## 开发与构建

```bash
npm install
npm run dev       # 启动本地开发服务器
npm test          # 运行核心肉鸽引擎单元测试 (Vitest)
npm run release   # 类型检查 + 单测 + 静态站点(dist/) + 单文件离线包(release/baishi-wending-web.html)
```

## 产物说明

- `dist/`：标准静态网页产物，可直接部署至任意静态托管或 Cloudflare Pages。
- `release/baishi-wending-web.html`：单文件全内联离线 HTML，双击浏览器即可游玩。
- `release/backend/`：纯静态 Cloudflare Worker 发布包（提供 `/` 与 `/healthz`，零运行时 AI 依赖）。
