## 浏览器验收

使用真实浏览器操作，不通过注入游戏状态跳过流程：

- 开局、第一次历练与古墓事件、显示成本并取得缺口铜铃。
- 装备法器后刷新，年龄、气血上限、资源与世界因果恢复。
- 闭关提高修为；突破失败保留修为并增加下一次成功率，之后成功结丹。
- 道证战中连续燃寿，命损增加而年龄与世界年份不变；第三回合重击提示可见，获胜后道证增加。
- 归隐须确认；选择一项澄明剑心后转世，新人生攻击增加八点，已得人间道证与古墓因果保留。
- 生平页展开上一世九条关键经历，包含实际事件选择、突破、道证、结算与传承。
- JSON 存档真实下载，再通过文件选择器导入；显示恢复人物确认后成功恢复。
- 390px 宽预览框中有效内容宽度 375px，scrollWidth 与 clientWidth 均为 375，无横向溢出；底部导航与修为条可见。
- 构建后的单文件 HTML 通过实际静态下载路径加载，闭关后年龄由 16 变为 19、修为增长、自动保存成功，未观察到游戏脚本错误。

单文件浏览器验收通过 HTTP 打开构建产物；不同浏览器 `file:` 自动存储政策仍可能不同，游戏提供手动导出／导入以迁移。

## 平衡与实际边界

三流派均有仅使用公开合法动作、第一世取得三道证并完成终局的准备路线。固定模拟中分别使用 133／136／132 次操作，余寿 151／118／175 年。相同初始装备闭关直冲且连续燃寿，在三个固定种子下均于终局失败；相同丹修准备路线改用连续燃寿也会失败，守势会改变战果。具体配置与方法见产品规划。

这些模拟证明指定路径及回归性质，不代表玩家平均成功率或真实游玩时长。首版没有多人、云存档、付费或排行榜。
