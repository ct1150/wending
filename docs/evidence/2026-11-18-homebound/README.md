## 内容与实现

新增独立 `events.homebound` 记录，从上界化神至大乘开放四幕：承诺与抢救船体、岑照和青禾的分歧、旧约影响下的合作、最终归处。两种承诺、两种部件、封舱/开放、航路与三个结局存在真实费用或可执行选项差异。船上可无资源退回，返港后可明确退出；工程和往返耗时，短时对话不跳日。结束一幕必须实际回港，人物中途寿尽不能冒记完成。

港外入口保留种簿和回山路径，旧 crossing 页在完整精确匹配后恢复原按钮。新章不要求玩家完成云渡或风隙，不改写这些旧事件。私人约定不传给轮回后的人物。

只读内容调查确认已有小满、钟荻等长线关系；本章补的是持续分歧与承诺后果，不能称此前没有人物故事。只读实现审查发现更早 seed 菜单变体被新入口挡住，以及邀请错误地说“起行才算应约”。主代理定点复核并修正。承诺确认与付费登船现为两个明确操作。
