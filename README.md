## 开始游玩

- **踏入仙途** 为新人物取名，查看固定背景与随机命签。身世不再参与随机或选择；重掷只改变资质和天赋，次数不限，刷新保留草稿。已有存档时先确认，直到新人物入世并保存成功才替换当前进度。
- **续写此生** 恢复当前人物的剧情、待续回合或死亡结算。无存档时此项不可用。
- **游戏设置**：调整画面主题和正文字号，可明确确认「重新开始」。新人物成功存入前保留原进度；重开不发轮回奖励。上次确认后若别的标签已换档，本页须重新确认。
- **备份与恢复**：导出当前 `.wending.jsonl`，或只读查看、单独导出先前人生。恢复备份须经校验和确认；在这里查看过去不会切换游玩人物。

剧情上方显示人物状态和修行目标。按钮列出实际需要的时间、灵力和物资。事件人生读到某段时可主动点「展开对白」或「展开描写」，由 Cloudflare GLM 补一小段文字。扩写期间可继续行动。进度自动保存在当前浏览器。

修行目标下的「仙路方向」会说明当前可接续的长篇旅程：问川、行旅、北山、三界海路，以及贯穿九境的守关与问鼎。点击前往只沿已有菜单翻到入口，不会替你接受委托、付出资材或决定结局。「此生行记」另列已经接下的事情和约期。

## 剧情与玩法

凡人流修仙推演引擎 v7 支持九境修行、寿元结算、长期因果和真实死亡后的轮回传承。从外院安顿下来后，进入「外出历练」可以接续以下旅程。

- 《问川图》有六折河上旧事。查井、访人或勘闸可以补全线索，自己决定何时落款。第四折签下的苗契会改变后面一段航程。
- 《行旅录》有引灯、观星和雪营三张路图。路程、潮窗和物件位置都可查阅。允许中途退出，也可从当前一程的起点重新规划。
- 《北山公簿》的九次处置发生在现世。炼气可辨井温，筑基能勘河床，结丹才能托起深处地脉。用自己的行粮、灵草或灵力办事，村落会记下谁付了代价。
- 第一折河事落款后，可从守闸旧札或物资页前往下界雾药谷。取水样、试滤方、修闸或向守泉会试手，都能帮你查到雾的源头。分水的决定会写进游记。
- 北山结案后，沉钟湾、中界白汀和上界照影台各有两趟船。船型、头潮的舱单与先抵岸的人会改变后续选择。前往更高一界需要境界和资用，港上接受修阵可以筹得渡费。已经飞升的人也可用水鉴联系旧港，委托当地船工按舱单启航。

在界渡台或一次跨界折返后，可以去泊船处整备。沉钟湾和白汀各有一班公具，可选铺岸路或助船下水，领全钱或用部分工钱换铁。先前运到港的人和器具会改变工期。工钱每港只结一次；港外还能自行采料，工棚可以调息、炼阵，再回渡台重试。

沉钟湾两潮交接后，中界的港信或「探访故人」可打开钟荻的《听息谱》。读家书、验原物，再用公料试音。中界三件音器可留符样或归还原主，这会改变上界三件的故障和接法。校完六件，可以在长桥或窗下办一场合奏，选两班亲自合练，也可提前开演。

从「安排修炼与突破」进入「调息、安排守关或验看功法」，可在凡人至大乘的九个阶段各做一次守关委托。选值守班、写明何时可以行动，再以本命功法闭关。公开底稿或封还原样，会改变下一班能拿到的凭据。第一次交割后可以陪牧女陶禾送鹿过栗溪。同行约定按人物实际日历算六日，十二年后驿棚有她的来信。这些相识和委托属于当世人物的经历。

守关簿九折合卷、人物真正达到渡劫境后，可在山门铸坊从三段人生各取一足。合器留堂或拆范分授都会留下鼎铭。当世仍可继续行动。自然身故后，新人物能读到先人留下的鼎铭传拓；封还的原样只留一处无名榫。

雾药谷分水后，回游记可沿坡背路进石肺三硐。公灯只有三格油，玩家可为实地查验花去一格，也可保留灯油直接处置。井底放水会改变中层的脚印，找到送药人的时间会改变最后的救援办法。二十日后外班接手。当世亲自查过的线索可随灯簿带往上界。

余寿已接近一次稳修加一次冲关的时间时，调息后可进山中药房。在同一处能搜寻材料、炼延寿丹、休整或服丹；每次仍按本命资质和当前境界结算耗时、材料、成败与药效。

从「寻找修行材料与生活物资」可以探访浮蚌渡。炼气、筑基、化神分别能找到地脉灵晶、金丹灵髓、虚空凝石。取压舱晶比剥废壳快，两种晶都能用来破境；下次上船时，守船的蓼会记得是谁动过船底。每次应下行程后开始计算潮期，中途闭关也会走时。若借走了凝石，到了炼虚还可以回来给蚌群重新定出归路。

修为已足、行囊还缺破境材料时，修炼页可直接去寻材。九种材料各有去处，行动前可以看到耗时和风险。缺粮可以沿路备办，取到材料后可回山调息或尝试突破。浮蚌渡仍有对应宝物时，玩家也能改走蓼的渡船。

筑基且本命功法完整或修补好后，验看功法可推演一式专修。分息听泉提高险路寻材的成功机会，回脉护身减轻失败伤势；两者每次使用都额外耗六分灵力。选择后须实际闭关练成，修期和收益沿用本命功法。改修失败会保留原术式，原有寻材走法也始终可选。

炼虚以后寻找合道灵玉、归一灵果或避劫雷印时，可以独自搜寻，也可以接走山驿的同行邀约。双峰石桥留下的扶手或吊索会改变果坞的运输和收果位置，果坞的水槽或风棚又会改变引雷坡的安全线路。每段交割都能领一份真正的破境材料。中途回山可以从「此生行记」接着走。

结丹时可从寻归魂印的入口或行粮路引进回声井。随巡井人慢走，或搭绳班赶路，首程都只交一份粮。跟水尺班辨假铃能缩短排水工期，跟绳匠学手势能更快架好吊篮。每一程都可以回山，井簿记住已走的路。愿意教晚班的人托绳，就要多留十二日，至多取一枚印。到了元婴可以回来定下新铃交给谁；已经跨界的人可借驿船寄回调好的副铃。

隔日接着玩，可以展开修行目标下的「此生行记」。它从当前存档列出已经接下的事，例如井路修到哪一段、还有几日退潮、苗盆何时可采。有期限的行动会提示可能错过的约期。「翻到」沿现有菜单回到那一页；具体出发、领取、还粮和如何收场仍由玩家选择。

北山九次议事可以直接落款，也可以先逐户询问。每议有两方当事人可追问，并能到案边对照实物；此前接渠、分席、划界等决定会改变后来人带来的凭据与处境。听取陈述不会自动答应请托，也不额外消耗日数或发放收益；到案边可暂缓离开，回来仍是未落款的那一议。

入山接下三日药圃差事后，可照旧直接做完，也可自己下田。第一日看天气清沟或架帘，第二日决定守豆苗还是药草，第三日交货领卷。保住豆苗的凡人还可以把它移进第一只随身苗盆。中途去修炼会错过这一季，但做过的工日仍然算数。

出山寻粮或采灵石后可到路灶备粮。两枚灵石换四袋炒米，用一日；两份灵草换同样四袋，要替灶上煎三日药茶。携苗修炼的人用完行粮，若还有可换的资材，出关时便能去路灶。每回苦修仍要自己决定是否开关。

亲自做过药圃工的修士到了中界，在「界域道路」可翻盐埠种簿。高垄和泉畦适合不同作物；试种九十日，可以留下守田，也可先去修行。收成决定递种船能带走活种还是田图。到了上界，玩家亲自决定把种交谁，或怎样让盐埠的经验帮到开田人。

想记录实际游玩时间，可在新玩法的「游戏设置 → 试玩手记」开始一段。离开冒险、切出窗口或两分钟没有操作会结束计时。在手记里核对休息秒数，也可给玩到的某一幕留一句感受。每个存档分别累计已确认时间，手记可单独导出 JSON，保存在本机。

从修行门槛或山口采药处可以领一盆试苗。凡人至大乘各有一畦。入定前可查看按本命功法稳修、苦修各要多少日，出关能赶上哪一候；也可以只守候，不增长修为。外出照常过日，错过末候就会散种。嫩收与熟收用途不同，留母土则能延长下一畦的嫩候。寿尽时尚未种下的母土可传给新人物，个人采收记录留在旧人生。

盆架下还有一块折山石。初见时，选一个自己想追寻的东西，带着泥人小满入定。井底、倒松林和雪脊共六关，后两重山在筑基和化神时展开。每关先选择留心的细节，再按本命功法稳修或耗粮苦修。出来以后要亲自辨路；走错了可以绕行，小满手里有你给的信物时也能带路。最初想回家还是寻源，会改变最后一道门和眼前的难题。已入山的人在晋阶后可以从结果页直接续行。

学过本命术式的人过了折山风筝一关，可以陪小满练过风口。听息教他辨节拍，护脉给他试走时的落脚处；付出一日和六分灵力后，再决定等他自己先走，还是两人合拍同行。这段经历会留到雪脊和分别时，即使两件信物都留在自己手里，小满也能回应迷路的同伴。

化神后走到雪脊，也可用已学术式进入返照。听泉追到回声背后，护身让自己穿过重复的足印；施术用一日、六分灵力，随后决定请旧影自选雪路，还是留下为后来人认路。这会留下不同的出关与分别记录。原来的辨路、绕山和请小满相助仍能使用；中途回山再来不会重复收取施术代价。

普通稳修需要两关以上时，可直接选连续稳修，也可在「提前几关出定」里自定修期。入定前显示合计时日、灵力、修为与暴露变化。修期依眼下境界、余寿和已接下的约期计算，给破境留出时间；遇到采候和交账日期，也会把收功的机会留给玩家。每关单独保存，出关后由玩家决定是否突破。

独自修炼的人出关后，也能直接比较继续稳修与付行粮苦修。缺粮时可去路灶换四袋，资材不足则自行寻粮；这些选择沿用本命功法的时间、灵力与失败风险，无须先接种植玩法。修为够破境后仍回到原来的整备与突破流程。

修期安排显示在单次行动之前。因采收、交账或还约而收功时，可直接查看对应行记，回到之前停下的地方再决定怎样处理。

初遇林砚后，在「探访故人」可听他谈起一只空药匣。渡口接力和石阶送件各有收件处，早年借粮或婉拒会留下不同的查件凭据。第一、第五和第十二年有三次交割，错过可以读回单。二十五年后处理旧匣，还能陪脚夫阿枳安排一次四日内的看潮之行。替班要花几天、是否需要行粮、哪条路赶得上，都取决于当年怎样教她和实际走过的药路。

旧匣交割时翻阅「三封回单」，可以打开渡头与石阶的合簿。两站要共用一根长梁、一卷油毡和一张铜版。每次托付后可以就地做工，也可以闭关再回访。亲自去两边走一趟，会看到没分到东西的人怎样应对。第三次交账后留在凡界，还能在晨雾里照自己定下的过站记号找船。

早期实时存档继续按原来的联网协议续写。它们会把出生旧事、天赋和上次选择交给模型，在流式预览期间就能阅读，回合保存后开放选择。

三界海路每港的两潮舱单办完后，「界域道路」可借原船轮航。三处泊位各有托货和收货日。先看船型能装几格，再决定取哪张货签、候潮还是花行粮拖航。到岸会按实际日期卸货结算。暂泊闭关也会过日，可从「此生行记」接着跑这一季。

轮航停在高坡夜学、靛坊或回光礁时，可在泊船处听岸上人的同行请托。答应捎带要花一日登船，并占一格到约定泊位；上界学徒还要回头去旧台，可能与送货方向相反。也可花两日和一份玄铁修渡具，请对方另约船，或继续原行程。收航回单区分真正送达、另借船和中途下船，不会把帮过忙写成已经把人送到。

到上界后，从「历练 → 炼制、跨界与其他准备 → 界域道路」可去白脊云渡。元婴、炼虚、大乘各有一班请托。你可以在岸上或随船按自己的功法闭关，出关后决定渡工怎样试航。以前留给井班的副铃和亲手建过的渡路都能派上用场。末班只够造一条船，公渡留下避劫雷印，教船的药师则留一枚延寿丹。

化神后，已交过一班云渡的人可从渡簿探访白脊风隙，不必先接完下一班。先查岩檐支点与船下回流，再以行粮勘路，或用已练成的听泉、护身术式开路。旧渡法与所用术式决定哪些路可靠；试走不稳的地方会实际受伤。入隙后可耗玄铁固定岩心，或付行粮疏开风槽。合体再访时，两种办法留下不同难题，可以保留或亲手改变。中途回山能从行记续行；已经付过的准备不会因改修术式而消失，原来的三班云渡也能继续。

## 新人生的成长与轮回

服务宣告支持新规则后创建的人物才使用本节玩法。原有无标记人生继续按出生时的合同重放；不能因为更换网页而重算过去。服务器暂不支持已标记的人物时，保留其存档和在途请求，等待兼容服务恢复。

| 身故后进入下一世 | 死因、最后行动和未清事项来自已发生的记录。新人生至多选择两项传承，按实际点数付款，余点留存。至多三条可追溯的前世回响会随完整备份保存；回响不自动发放物品或把旧债转给新人物。 |

## 全本参考如何参与剧情

保留 5.3.0 合入的全本 RAG 代码。私有语料导入及实际启用仍属独立发布步骤，本次可玩性修复不改变线上知识库启用状态。

全本证据覆盖 137,443 个符合条件的叙事段落；广告、标题、空白和作者感言的排除范围有逐项核算。7,936 个窗口是可追溯的自动切片，120 张精选卡是独立的抽象改编层；不将窗口数量当作精编卡数量或逐条语义审校结果。[覆盖与重建说明](docs/knowledge/README.md)给出数量、来源校验值和准确边界。

检索优先匹配本次行动，避开近期已用片段，并保留明确拒绝、告辞和失败跨界的结果。每次最多加入一张精选卡和两个证据窗口，总模型输入仍不超过 24 KiB。资料仅提供冲突与动机的参考，不能替玩家接受任务、发放资源、移动位置或改变规则判定。只有成功提交的剧情才更新本局引用历史，重试继续使用原冻结上下文；旧存档的有效内容优先于可选检索字段。

在生产策略有效时，参考资料缺失、损坏或读取超时，仍用原本的游戏上下文生成一次，不伪造引用。无效配置、请求取消和平台免费额度边界继续生效；GitHub 发布 HTML 不会开启生产知识库。


## 单存档与兼容

沿用 `wending-live-v1` IndexedDB 数据库、结构版本 3 和既有当前存档指针。升级直接读取此前实际选中的在线进度，不按时间重新挑选人物、不清空数据库、不改写历史或随机状态。旧导航中的存档列表和离线页面回到首页。

出生与开局待续事务在请求剧情前一起保存，刷新不会重掷。成功保存新人物后，原人物不再作为可切换存档提供；生成暂时失败时，新人物的待续回合可恢复。普通继续不会替换已死亡人物的结算，只有显式重新开始或轮回才创建下一人生。

完整备份保留 V5/CV4、v7 规则标记、格式 1/2/3 和关系记录兼容。导入在完整校验后才激活，跨标签页使用事务与预期身份检查，旧页面和迟到回应不能覆盖已经替换的当前存档。

旧版 localStorage 原始数据和底层历史记录保留供兼容与恢复使用，不作为额外存档槽提供。检测到旧版原始数据时，设置中的「备份与恢复」提供原样下载；旧固定剧情不再接入游戏控制器。

## 开发与构建

Node.js >=22，项目使用 Node 24。Playwright、Miniflare 与 Acorn 仅为开发依赖。

```bash
npm ci --ignore-scripts
npx playwright install chromium
npm run dev
npm run release
```

`npm run release` 执行完整测试、语法检查和网页构建，并重建 `release/`。后端打包须在网页构建之后执行：

```bash
SOURCE_COMMIT=完整40位源码提交 npm run build:gateway
```

| 产物 | 用途 |
| --- | --- |
| `dist/` | 静态网页目录 |
| `release/baishi-wending-web.html` | Worker 内嵌网页发行包，需要在线服务续写剧情 |
| `release/release.json` | `frontend` 字段记录版本、文件、字节数与摘要 |
| `release/gateway.mjs` | 静态发行网关 |
| `release/backend/` | 后端与模块清单；默认构建关闭推理，不可直接替换正式生产包 |

GitHub main 自动发布 HTML，保留既有 schemaVersion 1 的频道清单与不可变摘要路径。正式 Worker 使用内嵌页面，仍需单独更新实际部署并核对版本；离线下载旧地址 `/baishi-wending-offline.html` 返回 `410 Gone`。实际页面身份以 [`/healthz`](https://wending.868656.xyz/healthz) 为准。
