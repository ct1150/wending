# 整备去处：减少反复翻页

基线 `6f83fa6de17826a110fe8f509c0a632411393261`，分支 `feat/event-driven-story`。本轮改动是玩家可用的菜单导航，不新增剧情、不改资源规则、不部署生产。

上一条真实1191回合路线在化神之后有45次 `next-resource`、10次 `next-recipe`。这暴露了反复轮换页面的负担，但只代表该样例，不能据此推断真人平均耗时。新「整备去处」列出当前破境材料、普通物资与现有五种配方，让玩家直接查看指定页及当前持有量。实际搜寻、炼制、恢复和突破仍由原动作按钮结算。

## 实现与约束

`preparationStops` 从当前人生派生允许的目的地；同一资源/手艺节点的不同页使用独立ID。`noteRoutes` 沿原有安全菜单寻路，`openJourneyNote` 重新核对存档、修订和状态哈希，逐步提交已有菜单动作。没有直接写入节点或道具，也不穿过会改变承诺、奖励或故事阶段的选择。未决场景不可达时显示离开提示，已经到达则显示「正在这一页」。原行记、剧情按钮、手艺轮换和存档格式保留。
