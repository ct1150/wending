# 白脊风隙 · 回风孤标

本章已实现并通过规则、真实档案重放和浏览器操作验证；尚无真人体验时长结论。总目标仍为完整20小时文字修行冒险；本章不能独自证明该目标。实施证据见 `docs/evidence/2026-11-18-rift-beacon/README.md`。

## 为什么做这一章

完整组合路线的固定源码审计见 `docs/evidence/2026-11-18-combined-pacing/README.md`。1008个选择中包含大量导航；约4.4万去重码点也包含菜单和状态。不能把这些指标当游玩时长。现有山路的同页辨认题很短，增加另一段同类题不会改变整体结构。

选择扩展已经完成的白脊风隙，而非增加独立新委托或新战斗引擎。风隙已有真实的勘路、术式、定岩/疏风和合体再访，适合承接一个需要移动、调查、判断变风与自行返回的完整篇章。采用既有确定性规则和 authored text，AI只保留现有可选扩写。

## 故事与进入条件

须在上界，已完成合体风隙再访，即 `cloudRift.ending` 非空。后来的一班探路人曾在风隙外侧安放观风标，本次委托是取回记录、查明风向改变后怎样返回；没有滞留者等玩家救命，不让离开自动等于伤害他人。

旧云渡、试航和风隙结局完整保留。新标是后来的探路班安放，不把它追记成玩家以前做过的事，也不假称正常云渡已经改走风隙。已完成的风隙有效形态按 `anchor` 与 `ending` 共同计算，不能仅看最初 anchor。

完成风隙的总结页有两个原选择，可增加第三个“查看探路班的新来信”。旧页和在途选择须先按原合同恢复；离开再回来才呈现新入口。读信不接任务；明确起行才交一份粮并花一日，到外侧渡岸，记 `start` 为到岸日。

## 一段有去有回的探索

地点为外侧渡岸、上层岩檐、下层回流、背风标台。它们是原风隙之外的新一圈路，不重写先前入隙时的支点。

| 路段 | 基础日数 | 说明 |
| --- | ---: | --- |
| 渡岸 ↔ 岩檐 | 1 | 定岩历史留下踏点 |
| 渡岸 ↔ 回流 | 1 | 疏风历史留下接续节拍 |
| 岩檐 ↔ 回流 | 1 | 经过同一片外岩，允许交叉调查 |
| 岩檐/回流 → 标台 | 2 | 需在对应地点实际调查过，才知道入口 |

每处调查一日、一次，保存所得征象。普通阅读、重看地图不重复收费或刷资源。旧形态对应的入口不额外耗材；另一入口要花一份玄铁搭扣，消耗在实际通过时。所有进入条件、日数、物资和风险在行动按钮上显示。

第 `start+5` 日起变风。前往标台的行动若预计抵达日达到该日，按变风后的条件计价，不能以起步时尚未变风骗过边界。晚到仍可走，额外用一日、四分灵力稳住通路；不是章节永久失败，也不强迫重新开始。

只查一处时，从渡岸至标台共四日，可在变风前到达。先后调查两处至少六日，进入变风后的条件。第二处提供另一种地形证据与不同出口，玩家是在信息、时间与资源之间选择；不能在一页里直接写出唯一正确按钮。行动条件可明确，剧情判断不替玩家完成。

## 标台与回程

到台后先核对观风记录，得到实际带回的记录标记，不凭空增加背包宝物或修为。旧标的绳影与当天气流不一致，说明地图记录的是一种风候，而不是永远成立的位置。

玩家可选：

- 花两日、两份玄铁、六分灵力固定外檐回绳，打开标台直返渡岸的两日路。
- 花三日、一份行粮、六分灵力疏通浮标回流，打开标台到回流的一日路，再从回流一日到岸。
- 不改地形，按已走过的入口回退两日；变风后多一日和四分灵力，资源不足时仍有缓慢退回的办法。

两种工程日数、材料不同，改变实际可执行边，不只改结束文案。无修法也必须能返回：缓慢退回三日，不耗物资，不给奖励；不得因灵力耗尽把人锁死。选择回山结束当次探路，记录已调查内容与实际地点；从非渡岸撤回须真实走完回程，不能免费瞬移到修炼页。途中寿尽仍按引擎规则处理，未完成的修路和交割不能算成功。

带记录抵岸后才可交回探路班，形成一次性的 `delivered` 结局。未取记录也可明确收队，形成 `withdrawn`，不是虚构成功。不能重复接同章领物，章节不发资源收益。结局应分别写清调查过哪里、留下什么通路、实际交回了什么。

- 新增独立 `events.riftBeacon`，不扩写旧 `cloudRift` 字段或继承范围。实现时采用有限枚举、绝对日期、到访/调查标记及一次性结局，验证与真实动作顺序一致。避免记录可从路径推导的多份冲突状态。
- 规则仍经 `prepareChoice → pending → commit`，没有直接修改生命、随机数或库存的旁路。跨页、刷新、导出与导入使用现有档案层。
- 新节点 `sky-beacon-*` 与现有风隙节点分开；各页至多三个选择。路图是可查看的连接与已知条件，不自动走路，不自动发现线索。
- 起行后出现在「此生行记」，未起行仅作为「仙路方向」邀请。接近变风时行记提示剩余日数；闭关仍推动真实日历，不冻结天气。
- 旧历史页面只接受完整旧场景精确匹配，不为方便兼容放宽正文、选项或费用校验。旧 ready 与 pending 都要用真实前版本存档验证。
- 轮回后的新人物不继承本章私人路线进度；先人记录可在旧档只读查看。

## 必须证明什么

1. 四种初始定脉/再访组合产生正确的两种有效形态；有无专修术式都可走完，不强迫额外练功。
2. 两条入口、单处与两处调查、变风前/恰好变风/之后均有真实连续路线；时间和收费符合预计抵达日。
3. 两种修路与不修路都能实际返岸，余额不足可缓退；记录不会因导航、重复点击、刷新或恢复而重复领取/重复交割。
4. 中途回山后日历继续走，旧线索与费用保留，回来重新按当前风候检查路线。
5. 在付费移动 pending、调查后、标台修路后和交割后分别保存恢复，状态与费用一致；改造证据或不可能地点的存档被拒绝。
6. 原1009回合代表性人生不必接本章仍能完成；新的延长路线从真实角色接续本章并完成问鼎/保存，不用测试填资源代替。
7. 手机界面显示当前地点、去向、实际成本，基础流程零模型请求；完成后另记录真人体验。自动通过不称20小时目标达成。

## 实施后的明确约定

- 四处地点均为真实 place 实体，移动经 travel 规则结算，调查和修路经 explore 结算。阅读原纸为零耗时显式决定，不自动代玩家完成。
- 未读纸就离台可再入，重新支付当时通路费用；再次抵台更新最近入口与到达日。读纸后不再入台重复领取。
- 慢退三日到来时入口，再一日到岸；不是三日直接回山。交割后目标提示改为回看行程并继续修行。
- 变风是软条件，不是失败期限；闭关跨过变风日只提示费用变化。无需改动 practice-plan。
- 单份状态校验排除不可能日期与地点，完整存档再用行动历史核验事实；零耗时读纸不能仅凭快照辨真，重新计算哈希的伪造仍须被历史重放拒绝。
- 四种初始定脉/再访组合由局部规则矩阵覆盖；真实连续人物覆盖原疏风的保留与改变，以及无专修术式路线。不能称四种组合均完成全人生测试。
