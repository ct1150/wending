基线：`65ac7486173e16be7526a5ab26ec62d7c034e7a9`，分支 `feat/event-driven-story`。本次增加规则驱动的完整探索，AI 仍为可选扩写，基础流程不调用模型。不涉及生产部署。

## 实现

`rift-beacon.js` 保存独立行程，四处真实地点、调查耗时、预计抵达日变风、两种工程、原路和无资源慢退，以及返岸后的明确交割。旧定脉改变免费入口；未读纸就离开可重新入台。途中回山要先走回岸边，闭关不冻结天气。交割后不重复接签，不发额外修为或物资。

行记提供邀请、已知进度与软变风提醒。旧风隙记录和旧待续选择保持原样，完整历史场景精确匹配后才兼容新入口。零耗时读纸由显式选择产生；单份快照不能证明其真实性，完整导入通过行动历史重放核验。
