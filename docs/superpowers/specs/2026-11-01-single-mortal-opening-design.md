# 一个凡人开局：寒村少年，离乡入门

用户要求移除几种出身，由我们选定最合适的《凡人修仙传》式背景并直接发布。以下是本次选定的原创实现，不借用原著人物、门派或标志性宝物。

## 背景

主角十六岁，来自石溪村。父母健在，几亩薄田难以维持全家生计。主角随进山送炭的乡人来到栖云门外院，希望做杂役换取试修机会。此前只接触过发给来投少年的入门口诀，尚未引气。衣裳是母亲补过的，随身只有行粮和一件尚不知用途的旧物。

报到当天，管事正在分派差事。同来的少年，有人免去苦役被领进山门，也有人被退回。主角还没有选定差事、拜师、接受委托或取得仙家宝物。首幕由模型以这些事实展开，给出主动争取、问清规矩、谨慎查探或另寻出路等合乎本幕的不同办法；不使用预写按钮。

当前目标：在栖云门立足，弄清引气入体的门槛。
长期动机：从有饭吃、有活路，到凭自己的选择求长生。
最初悬念：同来的人为何待遇不同，杂役又凭什么换来试修机会？

## 方案取舍

- 多出身随机：继续分散开局身份，违背用户明确删除的要求，弃用。
- 固定原著人物与事件：会挤压玩家选择，且与项目原创要求不符，弃用。
- **选定：固定普通人的过去和入门处境，随机资质天赋，后续情节与选项由模型生成。** 起点有连续性，玩家仍能通过不同办法走出不同人生。

## 实现边界

- 新开局、重掷、刷新恢复的未开始草稿和轮回创建都使用 `mortal` 唯一新出身，背景 ID 固定。
- 命签不再展示或重掷出身；独立显示背景，再掷只变化资质和天赋，保留现有锁定规则。
- 新人生起点为「栖云门外院」，初始物资为两份行粮、零灵石，不凭故事文字赠物。已有轮回奖励继续按规则生效。
- 初始灵根、体质、功法和伴生物保留既有随机规则。功法视为此前领到的入门口诀，伴生物只是来历未明的旧物；开场不揭示天选身份或自动觉醒。
- 起点不附加强制人生期限，考核失败也不结束人物生命。
- 旧四种身份只留在旧存档解码和回放规则内，不进入新的角色创建。已有存档和哈希不重写。
- 首幕不再随机切换成资源、异象或同行开局；后续仍按真实行动与当前地点续写，不能反复重演入门。
- 不改变 6.1.1 的模型选项修正、单存档、流式展示和死亡结算规则。

## 验收

大量不同种子得到同一背景与起点，但资质天赋有变化；预览和正式创建一致；旧草稿和轮回创建不会回到四种出身；旧存档仍能继续与回放。真实模型首幕须在外院入门处境中给出可执行选项，后续选择能够推进。通过完整 CI 后合入，并保留 Cloudflare 的现有存档、知识库与密钥绑定发布。
