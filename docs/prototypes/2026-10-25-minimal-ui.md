# 百世问鼎：极简界面原型

日期：2026-10-25。状态：一次性探索，等待用户选择方向；未接入生产入口。

## 这次要验证什么

第一次打开时，玩家能否直接读懂眼前的人与事，并做出第一个有意义的选择。原型从谷口开始，没有姓名、出身、流派表单；常驻信息只有游戏名与封谷期限。费用放在会发生费用的动作旁，其他状态收在“状态”，选择经过收在“回看”。

## 三种结构

- **纸页（默认推荐）**：连续阅读的一页，短叙事、人物原话、两项等权选择。适合让文字承担主要体验。
- **对话**：人物发言与玩家回应交替，刚才的回答留在右侧，后果出现在下一句对话前。
- **行旅**：用四站短行程标出当前所在，正文围绕眼下要做的事，选择呈现为直接行动。

三版使用相同故事和费用，各自保留独立的内存状态，切换方向不会重开当前流程。宿主提供变体切换控件。

## 已接受的设计方向与本次新增提案

已经接受：叙事与世界责任驱动进展；主要结局表达不同价值；以连续三世检验后果，但不强迫死亡。本原型只验证第一段阅读与操作层级，没有把这些方向扩写成新结局。

仍待验证的提案：把角色身份选择后置；按当前行动渐进显示资源；“状态/回看”以展开正文的方式承载辅助信息。三版的视觉结构也均未定稿。

## 可操作范围

谷口两项选择 → 焦黑药簿两项承诺 → 陆槐与路引 → 证词、账册、地脉三线中最多选择两线 → 调查结果 → 明确结束演示。只有结束后提供重新体验。

初始样例：16岁，气血120，灵石24，药材3，封谷还剩8年，自身余寿84年。前面三个对话选择不耗年；两项药簿承诺均只发放一次药材2份。时间推进同时更新年龄、自身余寿和封谷期限，反馈展示封谷期限前后值。

调查费用来自 `src/game/story-content.js`：温渡治疗1年、3药材，其后可付8灵石承诺保护并取得完整证词，或免费记匿名半份；账册持路引查档1年，无路引等待副簿2年，其后分别演示付6灵石抄录或免费带走原卷，也可只留半份；通用地脉测绘2年、4灵石。流程压缩了路线进入和部分中间文字，没有复刻完整引擎、支线、战斗或结局。

没有持久化、真实存档、网络请求、外部资源、正式部署或生产代码修改。刷新即重新开始。“状态”仅供查看状态，无虚假可点的修炼按钮。
