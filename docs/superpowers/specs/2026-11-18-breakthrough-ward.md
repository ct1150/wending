# 高境护阵突破

长线人物在进入合体、大乘、渡劫时，失败且点数达到98会直接伤重死亡。现有守关与护身术式不影响这条规则。提供一个主动准备的替代选择，让玩家可以用真实资源控制风险；普通突破保持原样。

- 炼虚及以上、还有下一境且修为达到门槛时，在修行页第一项提供护阵入口；已有山中未完事务、苗盆转到护阵准备页第一项，不能遮挡护阵。旧修行页保留原选项，离开再回来才出现新入口。
- 护阵页有护阵突破、继续准备、返回修行三项；准备页保留达到门槛后的稳修，并提供手艺入口，不能因为新增护阵剥夺积累额外修为的选择。实际突破沿用普通突破的境界门槛、成功率、闭关时日、破境材料、失败修为损失、两层伤势与寿元结算，额外消耗阵盘1、法器1、灵力12。
- 无论成败器物均消耗。护阵只取消失败点数98/99触发的致命反噬，不保证成功、免伤或延寿。余寿不足仍途中寿尽。普通行动及历史结果不变。
- 无新的持久准备状态，没有先扣费再确认，也不自动制造器物。护阵入口的浏览不消耗时日或随机数。现有手艺页负责炼器与阵盘。
- 文案明确普通突破仍可选、护阵的代价和边界。结果页要说明护阵已耗用及成败，不以模型补充事实。
- 免费离线事件主循环保持；不引入AI请求，不发布生产。保护能力是本轮设计取舍，尚无真人平衡评测，不能证明20小时体验。

验证普通/护阵同一失败点数98、99、成功、低修为/重伤/缺材料/缺灵力、寿尽、旧高境修行页及未完成回合、真实备料到突破再导出刷新。仅规则边界测试允许构造数值，不将其当作原生通关证据。
