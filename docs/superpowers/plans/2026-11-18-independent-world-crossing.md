# 独行人物跨界通路

> **For agentic workers:** Use superpowers:executing-plans; main agent edits only.

**Goal:** 独行人物可以自行筹备已有古阵/飞升规则，按真正境界门槛跨界，不必先完成北山九议和港口两潮。

**Architecture:** 公共界域页增加方法/准备两页，复用v7已有ascend、ancient-array、explore、craft，不修改数值、随机数或结算。旧界域页精确兼容。

**Tech Stack:** JavaScript ESM、node:test、现有离线与IndexedDB。

## 设计与依据

5b86310原生个人路线186回合：药路最终分签、三次浮蚌寻宝、筑基听泉术式、折山六关/风口/返照/分别均完成，化神仍在下界。实际界域页仅有ascend。静态复核：公共页到中界需化神，到上界需大乘；古阵规则已有筑基/元婴门槛，但唯一事件按钮在海路页面。常规物资页只列下一境材料，飞升需要的skykey在化神时已经不是下一境材料，不能自然补采。

改变：公共界域第一项先进入方法页，提供飞升、古阵和整备返回。准备页提供按目的界域搜寻飞升信物、去现有手艺页炼阵、返回公共界域；灵石等原有资源入口保留。准备不赠物，不降低费用/境界/伤势，不增加新跨界方式。浏览不耗时，不自动飞升。上界现有入口不变。新节点只允许tier0/1，历史cross按钮仍有效，旧页离开再回来出现新入口。

这修复的是已有内容的可达性，不是新增20小时内容。测试中的游戏年月、186回合都不能折算真人时长。仅离线候选，未授权在本轮改变线上版本。
