# Cinematic title assets

- `title-cinematic.webp`: original artwork generated for 百世问鼎 on 2026-10-31, 1600 × 900, 226,492 bytes.
- `title-cinematic-mobile.webp`: crop of the same original artwork, 600 × 1000, 93,318 bytes.
- Art direction: a solitary swordsman on a near cliff, Chinese mountain peaks and a dawn cloud sea, far-right ruined gate and pine branch, charcoal teal shadows and pale warm light, quiet left area for the title. No text, logos or third-party characters in the image. Created with the built-in image generator; Sharp used for crop/resize and WebP encoding only.
- `title-brush.woff2`: four-character subset (百世问鼎) of Ma Shan Zheng, distributed under the SIL Open Font License 1.1. The name used by the CSS is Wending Brush to identify the subset; the underlying font metadata remains intact. License and copyright are in `title-font-OFL.txt`; the complete OFL is also embedded in the font name table (name ID 13), so the self-contained offline release carries it.
- Font source: https://github.com/google/fonts/tree/main/ofl/mashanzheng ; subset retrieved from the Google Fonts CSS service and encoded as WOFF2 locally.

The images and font are referenced exactly once each by CSS URLs so the existing offline builder embeds them. No external network access is needed for title art, type or effects.
