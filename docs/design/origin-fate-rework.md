# 问鼎：命签与出身重构方案（待实现）

## 目标
把开局从数值刷骰改为可理解、可重玩的「身世 + 两项命格 + 资质」组合。保持单屏、对话与选项的极简体验。

## 重要现状
main 分支 package.json 为 3.1.0；此前口头描述的出身、双天赋等改造尚不能当作已发布功能。实施前应核对新分支、现有存档格式与测试。

## 玩法原则
1. 出身必须改变首段剧情、起始关系、至少一个专属行动；不能只更换开场文字。
2. 命格必须在首局前 10 次选择内至少一次产生可观察的专属机会；既有好处也有代价。
3. 资质采取固定点数池，避免刷到全面碾压的最优解。
4. 掷骰允许锁定最多一项命格后重掷；锁定、随机种子和入世结果必须持久化。
5. 稀有不等于全面更强；每项强命格都需要条件或代价。
6. 前世奖励优先解锁可选命格/特殊出身，而不是永久堆数值。
7. 旧存档必须无损恢复；新开局才采用新规则。

## 第一批命格
- 过目成诵：更容易参悟残卷，但实际修炼仍需时间与材料。
- 听息敏锐：察觉危机、获得避战选项；不能自动看破一切。
- 草木亲和：采药有额外机会，但容易被灵物牵连。
- 丹火不稳：炼丹可尝试特殊配方，失败时更易伤身。
- 天生剑骨：剑术入门快，但体质恢复不占优势。
- 刹那慧心：短期参悟能力突出，付出明确寿元。
- 福祸相依：偶遇机缘的同时伴随可见风险。
- 无灵根异相：常规引气受阻，但可能探索异法筑基。

## 组合事件示例
药铺伙计 + 过目成诵：识破账册中的残缺丹方，可选择揭发掌柜或私下交换。
渡口短工 + 听息敏锐：听出木匣中的呼吸声，提前决定放生、藏匿或交给船主。
山村药童 + 草木亲和：采药时灵草主动靠近，却引来守药异兽。
刹那慧心 + 无灵根异相：参悟一条危险的旁门路径，明确展示时间和寿元成本。

## 最小验收
- 4 种出身各有独立开场与至少一条独立行动路径。
- 8 种命格均能在实际剧情中触发，不仅改变描述文字。
- 每种出身至少两种不同有效策略，不产生软锁。
- 组合命格在前 10 次选择内可见，选择后有真实状态后果。
- 锁定重掷、刷新、导入导出、旧档恢复均有自动测试。
- 真人试玩检验：60 秒能说明自己的身份、目标与这局的特殊机会。
- 先通过 CI 和完整一世回归，再发布 Cloudflare，实际网页复测后才宣称上线。
