# 百世问鼎 · 产品与玩法规格

目标产品版本：**2.0.0 对话与选项版**。更新：2026-10-25。代码实现与本地发行验证见 [QA](QA_REPORT.md)，实际 GitHub／生产发布与 UI 验收仍待控制方完成。当前生产为 1.2.0；本页不是上线声明。批准设计见 [设计稿](superpowers/specs/2026-10-25-dialogue-only-design.md)，旧规则与数值原样保留于 [1.1.0 历史规格](PRODUCT_SPEC_1_1_HISTORY.md)。

## 需求与方案

玩家通过当前故事里的行动完成修仙冒险，不在正文与修行管理菜单之间反复切换。一次选择要能说明在救谁、使用哪份证据、付什么代价、承担什么责任；前世变化必须成为后来世界的真实条件。新人生采用独立 v3 journey 引擎，原生 JavaScript、零运行时外部依赖，浏览器本地存档和单文件离线发行。

新开局使用十六岁的云归直接入场。当前情境通常给两到三个行动，真实交接／死亡结算可仅一个。对白、选择与回应保留在同一阅读流中；历世生平、前世行文、已得传承与旧档资料在同页按需展开。身体处境由正文说明，当前物品数量与余寿在相关行动的成本说明旁显示。帮助与更多承载说明、备份、下载及明确确认的重置。姓名、出身、职业、换装、闭关和敌我血条不构成新人生主循环。

## 实际内容与通关

| 阶段 | 已实现的承担 | 真后果与边界 |
| --- | --- | --- |
| 人间：药谷旧火 | 最多深入证人／账册／地脉两线，查证、救援、决定谷地安排，亲自完成交接 | 共守保灵种与地方权属；宗门接管保留经营权让渡；焚种迁民永久失种。治疗、同意、实物、救援与公开真相分别记录 |
| 幽冥：亡者旧账 | 依谷地现有制度纠债或暂封、核实实际来源、保留授权、裁定可责范围或有限共担 | 不用灯诀补全签令事实，不追家属旧债；有限裁定不冒充全案侦破 |
| 天界：立约问责 | 真实地方授权或个人小约、限制代际连坐、有限供药、实际送达副本 | 未获授权不代地方承诺；原件、认证抄本与匿名记录区别保留；不足供药不由文书凭空变足 |
| 三界问鼎 | 以证据问责或有限共担过鼎火、约定停止权、回到实际职责 | 三证和今生同意均须真实成立；缺证可有限补交；通关不复生温渡、不复原毁种、不保证所有目标成功 |
| 后世：有限三类责任 | 医馆、庄园、迁民各一条适用任务；共十一种结算结果 | 稳定任务全世界只完成一次；完成后保留相应短回声并去未完主章，无无限重刷或虚构新篇 |

两种方法均能从第一世、无可选能力、无注入进度的公开动作走到胜利。没有药、失去原件、重伤或准备不足仍有作者写好的继续、让步、有限责任或明确结算，不保证最优结果。普通冲突一次选择结束，药谷、幽冥核证与终局等重要冲突最多三次。完整作者条件与后世结果表见 [作者契约](story/dialogue-journey.md)。

## 核心规则

### 时间、寿元、伤势与成长

余寿为 `lifeLimit - age - lifeDamage`。凡人／筑基／结丹／元婴寿限为 **80／160／240／320**；关键主线承担与交接确定成长，直接开放下章所需通行，获得道证仍须真正完成相应事件。境界成长不清零命损，不依赖可选能力、随机突破或死亡次数。

历时行动同时推进年龄和世界年份。人间学习、完整测渠、普通救援、共守修渠、普通认证抄账各一年；药理学习一年，学习加服务换一包药合计两年；后世服务按选项明示实际一或两年。跨界叙述本身不额外扣整年。**封谷仅以最多两条调查限制，没有旧规则的八年倒计时**，不会把学习与耗年再叠成隐藏期限。

个人燃命只增加命损，不推进世界。学习燃命需三年命损；开短门或单独护记录需五年；药理组合需一包真实药与三年命损。普通有成本行动必须支付后仍活着，当前余寿必须严格大于成本，不能提前借下一境界寿限。选项先检查成本，原子提交，无法执行时不扣费、不重抽、不发奖。

伤势为无碍／负伤／重伤，影响相关方法；没有通用 HP 磨血。物品为具体药包和证物，无通用灵石商店。已经花掉的同一包药不能用于另一场承担，交出的原始账页不能重新出现。

### 有限学习与随机

六种方法为护人、辨言、引魂灯、药理、定契、燃命，每大章两个有限候选。进入机会场景时依据已继承方法筛选并抽一次，立即存入状态；读取、帮助、回看、保存与刷新不推进随机数。每大章最多一次可选学习，一世最多三项新方法，加最多一项当前传承。拒绝始终有免费后继。

方法改变相关行动：护人付伤势保护实际证人、辨言识别无证推论而不造证、灯只保自愿片段、药理用实药作有限示范、印约束真实同意、燃命付个人余寿。三种真实可达组合为护人＋魂灯、辨言＋定契、药理＋燃命，均需真实来源、相应经历或当前自愿证人，不以统一折扣代替故事差别。

### 生命结束、胜利与跨世

问鼎胜利是正生命 `victory`，有总结但尚无当世生平。选择下一世会明示共同走过剩余寿年，再记录一次胜利生平、增加一次十六年新生间隔。退休实际走完余寿；明示致命燃命只烧尽个人余寿，不给普通奖励。死亡和退休本身不发传承。

新规则中真实学习和医馆共议／共同凡药园成果立即进入已得传承历史，不等于当前激活。下一世只有一项情境方法生效：有沿用项时保留它并给至多两项真实替换，无沿用项时至多三项真实候选，无候选时记忆新生。已得历史不因候选上限而丢失；未在当前情境唤起的旧藏保留名字与来源，不叠加数值。

道证、世界事实、任务和完整生平／行文跨世保存。任务记录有稳定 `episodeId`、`generation`、单调 `sequence` 与 `outcomeId`，允许同世多章，不允许同一任务跨世重发奖。世界年份使原人物老去，接任者承接职责，不继承死者私人关系；毁种、死者、旧失诺和真正机构权利不会因轮回抹去。当前物品、学习机会、个人授权、陪行意愿与当世职责重置。已持三证仍须今生有限同意，已完成问鼎者进入诚实回顾。

### 存档与兼容

产品 2.0.0 新人生保存为 `version: 3 / mode: dialogue / contentVersion: 1`，原存储键不变。统一分发先严格验证：v1 走原有 v1→v2 校验升级，合法 v1/v2 当世继续旧引擎，不中断战斗或补造经历；真正结算并明确选完旧奖励后才交接新人生。旧候选不等于已拥有，迁移不擅自解锁全部候选。

备份保留精确原始字节和完整旧档归档，也保留当前结算 checkpoint 和唯一 prepared v3 目标。备份写入及读回验证成功后才替换当前档；部分失败仍可导出、刷新恢复并重试同一目标，不再次耗年、换种子或出生。较新普通旧进度未写入当前档时，显式恢复后再继续，不能静默丢弃。坏档／读取失败不自动覆盖。超出既有大小边界的归档转换会先拒绝，不截断历史；可继续导出原进度。详细接口见 [引擎契约](ENGINE_CONTRACT.md)。

这些证明路径存在和后果区别。当前默认寿命余量宽裕，不能据此声称已实现强寿元压力。**20–30 分钟一世、真人阅读与选择节奏、寿元张力仍未测量。** 原管理玩法装备与直冲对照属于 [历史 1.1.0 平衡记录](PRODUCT_SPEC_1_1_HISTORY.md)，不用于新版数值结论。

## 实现、验证与交付边界

UI 只消费公开 view 与命令，v3 引擎／内容不依赖旧 HP／修为接口。统一保存分发隔离两代规则。静态 ES 模块、相对资源、无外链字体或运行服务；现有普通 Worker 内嵌同一离线 HTML，不配置自动发布或迁移 Static Assets。

行为验证覆盖真实公共胜路、有限条件矩阵、无空后继、选择上限、奖励来源、RNG 稳定、三类十一结果后世、旧档 provenance 与恢复事务。条件矩阵是作者 resolver 层检查，不声称所有合法存档或所有故事路径均已遍历。Node UI harness 证明特定控制与焦点请求，不等同浏览器真实布局、可访问性或视觉验收。

触控至少 44px、320px 无横向溢出、浅深色可读、键盘和历史阅读连续是规格要求。新版获准生产 UI 验收、真实手机、读屏与真人节奏尚待观察；旧版浏览器记录不能替代。实际远端精确树、PR、CI、合并 SHA、Worker 部署、health 和实际下载均须控制方另行核实后才能称 2.0.0 上线。

不提供多人、账号、排行榜、付费、即时大模型剧情、无限新篇、完整家族／宗门经营或无限境界。有限内容已有三界与轮回闭环；并非把开场切片当完整改版。
