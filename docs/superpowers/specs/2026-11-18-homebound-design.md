# 归航者：跨境界的持续冲突

主代理依据既有自主推进授权选定，现已完成本地实现、档案和手机操作验证。继续完整20小时冒险目标，不能用四幕、字数或日历证明时长。实际覆盖与限制见 `docs/evidence/2026-11-18-homebound/README.md`。

## 缺口与取舍

现有折山有持续伙伴，云渡有跨境交班，问鼎有继承；不能声称此前没有长线人物。新线补充的是一个持续与你合作、又可能反对你目标的独立角色，以及早期承诺怎样限制后来的合作。采用四幕固定叙事与规则选择；不用每回合模型即兴，也不用新增通用剧情平台。

化神后在上界港外遇见舟灵岑照。她由末代船长的归愿化成，想把残舟与舱内回声送回已经消失的故乡。回声逐渐有了与旧乘客不同的愿望。她不是因玩家不接任务而受罚的限时人质；各幕之间船停在安全锚地，允许先修行，也允许明确退出。高境玩家可连做，正文不虚构中间经过几百年。

## 四幕及可执行后果

1. 化神「船还记得回家」。先零耗时明确承诺“先听醒来的人怎样说”或“帮你修成归乡船”，再显式起行两日一粮。登船可分别查龙骨和小艇，各一日。共同吊臂只能在一次撤潮里拖走一件：保船骨或放小艇。选择改变第二幕现场以及第三幕可借的部件，另一件不能刷取。调查对应处后工作两日，否则四日；保骨另用一铁，两者用四灵力。回港两日。
2. 炼虚「她给自己取了名字」。可听岑照的旧航歌、听新苏醒者青禾说自己的名字，短时对话零耗时。开放舱门让回声自行改变，或暂保封舱让故乡图保持完整，均两日四灵力，不发资源。开放与归乡承诺相冲突时岑照会在第三幕拒绝掌舵；不是一个随便加减的好感数。封舱也明确失去自主航行助手，后面可付工期解开，不能宣称两全。
3. 合体「两条不能重叠的水道」。看锚湾或外海道，各一日。选择修锚湾或开航道：基础三日四灵力；缺对应部件增加两日一铁；锚湾有完整封舱图、航道有开放后同伴协力时免基础四灵力。违背归乡承诺且曾开放舱门，岑照不掌舵，玩家额外付四灵力。新路线只影响这艘船，不改写旧云渡/孤标路线。完成后回港两日。
4. 大乘「归航不是归还」。通过零耗时对话谈清故乡已不存在与青禾自己的愿望。可以留舟为锚居、让醒来的人自主启航、熄去旧舟核让他们各自离去。自主启航须开放舱门；已封舱者可以另花两日四灵力解开，此后不能恢复旧图优势。结局分别三日/三日/一日，锚居或启航与第三幕路线不合时另付两日一铁。熄核不耗物资。选择之后亲自回港两日才落最终完成标记。

每幕调查不是答题密码，不读也可作决定，按钮展示实际代价。没有随机死亡或额外资源奖励；行动途中寿尽仍由引擎处理，不能写入未做成的进度。船上始终可以无物资两日退回港外，保留当前调查和承诺；重返当前幕再付两日一粮。退出须先回港再明确确认，结束全线而不是重置资源。没有强制玩家等天数的开门计时。

## 数据与兼容

独立 `events.homebound`：`pledge`、`visits`、`place`、`at`、`released`、`ending`、`ended`。承诺后未起行时visits为空，最多四项，每项 `start,seen,choice,decided,done`；seen两位调查标记，choice按幕有限枚举，decided为工程完成日，done为实际回港完成日。released仅第四幕解封产生。ending完成前三幕和第四幕实际返港后设置，也可在港外明确 withdrawn。校验有限枚举、时序、境界、地点与页次；完整历史重放证明零时决定，快照不充当真实性凭证。

实施裁定：额外记录decided以拒绝工程完成同日就冒记返港；纯对话遵循既有一天内多次互动约定，不强行消耗一天。只读调查确认已有小满/钟荻的长线关系，新线不是填补“没有人物”的空白；要保留岑照对失约的独立回应，不能只重复两处征象的答题。
