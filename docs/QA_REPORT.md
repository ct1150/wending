## 已实现的 4.2 体验

首页固定入口为「踏入仙途 / 续写此生 / 游戏设置」；首页只读，首次访问不创建人物或生成故事。新玩家默认进入实时创建，续玩恢复上次选择的旅程，已有离线档沿原规则继续。活着的角色也可另开独立旅程，原人物与历史保留并可从「切换存档」访问，不伪造死亡结算或奖励。

剧情下方可直接访问「历史对话 · 游戏设置 · 返回首页」。游戏设置提供跟随系统／纸白／夜读、标准／较大字号，以及存档导入、导出和旅程切换。导入需要明确确认；原旅程或损坏存档的原始字节先保留，备份或写入失败时阻止覆盖。重新打开先显示首页，同一标签页刷新恢复页面、创建草稿或剧情；单文件离线玩法继续保留。

本次变更不调整模型、后端、协议或计费策略。方案与验收条件见[确认设计](superpowers/specs/2026-10-29-title-screen-design.md)。
